1 · “완료”의 범위를 먼저 분명히 했습니다

현재 완료한 것은 순수한 protocol·client·host, iframe transport, 실제 브라우저 예제와 그 검증입니다. 한 호스트 페이지에 서로 다른 출처의 Portal을 함께 실행할 수 있습니다. 네이티브 앱용 실행 코어와 운영 환경의 호스팅은 별도 범위입니다.

README는 기능이 없는 것처럼 남아 있던 체크박스를 실제 상태로 바꾸고, 실행 방법·실제 API·검증 근거를 연결했습니다. 영문 완료 기록은 요구사항별 근거와 기존 명세의 미결 사항을 함께 보여 줍니다.

2 · 일곱 가지 조건이 모두 근거를 갖췄습니다

완료 조건확인한 내용

자동 테스트는 1,131개·39개 파일입니다. T20에서 루트·실험 타입 검사, Biome, 두 예제 빌드와 Chrome 156 관찰을 마쳤습니다. 수동 관찰을 자동 테스트 개수에 더하지 않았습니다.

일곱 항목과 보안 명세 §9의 각 요구사항을 코드·테스트·관찰 기록에 연결한 표에서 확인할 수 있습니다. “완료”라는 문장만 남기는 대신 근거를 따라갈 수 있게 했습니다.

3 · 인터페이스의 설명도 실제 코드와 맞췄습니다

README에 남아 있던 “두 메서드” 설명을 고쳤습니다. 실제 경계는 세 메서드입니다.

interface Transport {
  send(message: JsonValue): void;
  onMessage(handler: (message: JsonValue) => void): () => void;
  close(): void;
}

실제 Transport 계약입니다. send는 메시지를 제출하고, onMessage는 받을 함수를 등록해 구독 해제 함수를 돌려줍니다. close는 연결을 닫습니다.

낮은 단계의 send가 void를 반환하는 것과, 미니 앱이 호출하는 기능이 비동기라는 것은 다른 층의 이야기입니다. 호출자는 client.call의 Promise로 결과나 오류를 기다립니다.

await client.initialize();
const profile = await client.call('profile.get');

README의 예시도 현재 createClient와 iframe transport를 사용하는 형태로 맞췄습니다. 처음에 initialize를 실행하고 그 뒤 기능을 호출합니다. 일반 call의 반환값은 unknown이므로 화면에서 소비할 필드는 실제로 확인합니다.

작업 안내 파일도 현재 합의된 방식으로 맞췄습니다. 에이전트가 테스트·구현·검증을 진행하고 task마다 코드와 쉬운 한국어 설명을 남깁니다. 이전에 직접 입력하며 공부한 자료도 그대로 보존합니다.

4 · 남아 있는 질문을 해결했다고 표시하지 않았습니다

항목현재 상태
같은 출처의 새 문서와 오래된 응답이전 응답이 새 문서의 같은 번호와 연결될 수 있는 문제는 SPEC §11의 알려진 한계
상대 연결 종료 감지일반적인 종료 신호는 미정. 로컬 client.close와 구분
동의 UI·호출량 제한정책 미정. 오류 코드가 있어도 기능 구현을 뜻하지 않음
여러 Portal의 통신여러 출처를 한 페이지에 담기는 가능. 앱끼리 주소 지정·방송하는 API는 미정
네이티브·운영용 호스팅현재 브라우저 개발 범위 밖. 운영용 moonpool:// 원칙은 유지
다른 브라우저·메모리 회수현재 기록을 모든 엔진·URL 방식·GC 보장으로 확대하지 않음

이것들은 명세가 이미 남겨 둔 질문이나 현재 단계의 범위입니다. 완료 표시를 위해 명세를 바꾸거나 새 정책을 만들지 않았습니다. §9 보안 근거도 기록한 개발 구성의 코드·테스트·관찰과 함께 읽도록 정리했습니다.

저장소의 수명도 구분합니다. Portal을 새로 만들어도 바깥 provider가 살아 있으면 앱 데이터가 유지되지만, 메모리 provider 자체를 새로 만들면 데이터는 초기화됩니다. 파일을 읽는 loader는 경로·심볼릭 링크가 패키지 밖으로 나가지 않도록 책임져야 합니다.

5 · 마일스톤 완료와 패키지 배포는 별도입니다

{
  "name": "@moonpool/client",
  "version": "0.1.0",
  "private": true,
  "exports": { ".": "./src/index.ts" }
}

현재 패키지 설정의 일부입니다. 버전 문자열이 있다는 사실만으로 npm에 공개됐다는 뜻은 아닙니다. 지금 산출물은 저장소에서 실행하고 검증하는 소스 작업공간입니다.

프로토콜 0.1은 여전히 draft·unstable입니다. 배포·태그·공개 패키지 발행은 별도 작업입니다. 현재 마일스톤의 근거는 실제 구현과 검증 기록이며, 호환성 약속을 새로 추가하지 않았습니다.

6 · 코드 기준은 보존하고 문서 일치를 확인했습니다

T21은 문서와 상태 정리입니다. 실행 코드·테스트·설정의 내용은 T20 기준과 같게 유지했습니다. 기존 전체 검사 결과를 연결하고, 새 문서의 링크·체크박스·스터디 지도·심볼릭 링크가 올바른지 확인합니다.

README, CLAUDE.md의 일곱 가지 체크박스, CHANGELOG, HANDOFF와 task 목록을 같은 범위로 맞췄습니다. AGENTS.md와 Copilot 안내 파일은 계속 CLAUDE.md를 가리키는 심볼릭 링크입니다. SPEC와 기존 ADR의 결정은 그대로입니다.
